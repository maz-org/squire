# docs/plans

Prose planning and decision documents: tech specs, engineering reviews,
decision reports, iteration logs, and closing reports. These are the
documents agents and reviewers should read — authoritative decisions live
here.

**Do not commit generated eval run reports here.** The eval harness
writes `<label>.json/.md/.tsv` report trios; cite them as evidence from
the PR or Linear ticket and let git history keep them at their commit —
do not leave them on main (they are large, they go stale, and stale
results mislead both agents and reviewers). The accumulated reports from
the Table Turnaround epochs were pruned on 2026-07-11; every removed
report remains readable at
<https://github.com/maz-org/squire/tree/9be06d93f2949418b67fc8aa7d9439b733523b68/docs/plans>.
